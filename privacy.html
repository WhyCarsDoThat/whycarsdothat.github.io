Privacy Policy

Last updated October 25, 2026

Who we are

Why Cars Do That is a YouTube channel that publishes short explainer videos about how cars work. This policy covers this website and the "Why Cars Do That Uploader", a private tool the channel owner uses to publish the channel's own videos.

This website

This site has no accounts, forms, cookies, analytics or advertising. It is hosted on GitHub Pages; GitHub may keep standard server logs (such as IP addresses) as described in GitHub's privacy statement.

YouTube API Services

The uploader uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service, and Google's handling of your data is described in the Google Privacy Policy.

The uploader and Google user data

The uploader is used only by the channel owner, on the owner's own computer, to manage the owner's own YouTube channel. With the owner's permission it uses the YouTube Data API to:

  • upload and schedule the channel's videos and set their titles, descriptions, tags and thumbnails;
  • add those videos to the channel's playlists;
  • read the channel's own video list and settings, and update the channel's branding.

The sign-in token is stored only on the owner's computer. No Google user data is collected from anyone else, sold, shared with third parties, used for advertising, or used to train AI models. The uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube itself is governed by the Google Privacy Policy and the YouTube Terms of Service.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the token on the owner's computer also ends access.

Viewers

We don't collect personal information from viewers. Comments, likes and subscriptions happen on YouTube and are handled by YouTube.
